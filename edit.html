🔑 GitHub 令牌（首次配置，之后免登录）

电脑打开 github.com/settings/personal-access-tokens/new：
① Repository access 选 Only select repositories → asset-monitor
② Permissions → Repository permissions → Contents → Read and write
③ Generate → 复制令牌粘贴到下面。令牌只存本机浏览器（localStorage），只授权这一个仓库。
